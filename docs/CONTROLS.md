# Controls

Two schemes (Settings → Controls, or the pause menu): **Simple** (default) and **Classic**.

## Simple (default) — stick + 4 buttons + sprint

| Button (keyboard / pad) | With the ball | Defending |
|---|---|---|
| **A** / B — Shoot | tap = placed shot, hold = power; press before the ball arrives = first-time shot / volley / header. Hold **W** while shooting = finesse, hold **D** = chip | slide tackle |
| **S** / A — Pass | tap = pass to the player you face, hold = through ball (hold longer = further). Press **S** while charging a shot = fake shot | tap next to the carrier = tackle; hold = jockey |
| **D** / X — Cross | cross from wide, lob elsewhere | switch to the best defender (+ direction = that player) |
| **W** / Y — Close control | tap + direction = skill move; hold = shield the ball | hold = teammate presses |
| **Shift** / RB, RT — Sprint | double-tap = knock-on (push the ball ahead and race) | |

**Gestures with the ball (no button):** quick stick reversal = drag-back (roulette while sprinting) ·
sideways flick near a defender = ball roll · hard cut while sprinting = chop · stop next to a defender = automatic shield.

**Perfect timing:** release a shot, through ball or cross while the power bar is in the light zone (it turns
green) for a much more accurate ball; tackle while the dribbler's touch is long for a "Perfect tackle".

2 players on one keyboard (Simple): P1 WASD move, F shoot, G pass, R cross, E skill, Left Shift sprint ·
P2 arrows move, K shoot, J pass, U cross, O skill, Right Shift sprint.

# Classic

Every keyboard action can be remapped in **Settings → Controls** (click an action, press a key or mouse
button; **Esc** cancels). A warning appears if the key is already used by another action — that is fine
when the two actions never happen at the same time (attacking vs defending).

## Keyboard (defaults)

| Action | Key | Notes |
|---|---|---|
| Move | Arrow keys | |
| Sprint | E | hold |
| Shoot | A | hold to charge, release to shoot. Height follows power |
| Power shot | A while holding E | faster, less accurate |
| Low driven shot | A while holding S | stays low |
| Finesse / chip | hold Z / C, then A | curled / chipped |
| First-time shot / volley / header | press A **before** the ball arrives | struck without a trap; volley or header by ball height |
| Ground pass | X | hold for power. Press before the ball arrives = first-time pass |
| Driven pass | X while holding E | |
| Through ball | W | the stick steers where it goes; power = how far ahead |
| Lofted pass / cross | D | from wide areas = cross. Hold S = low driven cross |
| One-two | X while holding Q | you keep control and run; the receiver plays it back |
| Fake shot | press X while charging a shot | can wrong-foot defenders and the keeper |
| Skill move | R + direction | forward = step-over · sideways = ball roll · back-diagonal = heel chop · back = drag-back · back + E = roulette · double-tap R = flick-up |
| Shield the ball | hold S (with the ball) | back to the defender; strength decides |
| Jockey | hold S (without the ball) | stays goal-side of the carrier |
| Second-man press | hold C (without the ball) | nearest teammate presses |
| Standing tackle / slide / steal | Q / F / H | |
| Switch player | Tab (+ direction) | with a direction: the teammate that way; without: the best-placed defender |
| Celebration | 1 – 4 during the goal replay | |
| Camera / pause / mute | V / P / M | |

Pass assist at **0** (pause menu → Game Settings) turns every pass into a manual pass along the stick.
